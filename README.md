webman-covers

Scripts pour Jaquettes WebMan PS3.

Télécharger les scripts : https://lu-ghb.github.io/webman-covers/

Utilisation détaillée juste ici : (vidéo pas encore sortie...)

Les scripts

À utiliser dans l'ordre.

#	Script	Ce qu'il fait
1	1 - Jeux .ISO dans Dossier.bat	Range chaque fichier .iso dans un dossier portant le même nom.
2	2 - Renommage Jaquettes.bat	Renomme l'image présente dans chaque dossier avec le nom du jeu .iso.
3	3 - Conversion Images PNG 120x120px.bat	Convertit les images en PNG (jusqu'à 120x120 px) de 22 Ko maximum.
Utilisation
Télécharge les scripts depuis la page ci-dessus.
Place-les dans le dossier qui contient tes jeux .iso.
Script 1 : double-clique dessus. Chaque .iso est rangé dans son propre dossier.
Mets l'image de jaquette de chaque jeu dans le dossier correspondant.
Script 2 : double-clique dessus. Chaque image prend le nom du jeu.
Script 3 : double-clique dessus. Les images sont converties en PNG léger, y compris dans les sous-dossiers.

Formats d'image pris en charge : jpg, jpeg, png, webp, bmp, gif, tif, tiff, avif.

Prérequis
Windows
ImageMagick pour le script 3 (il est détecté automatiquement s'il est installé)
À savoir
Fais une copie de tes images avant le script 3 : il remplace les images d'origine par les versions converties.
Si une image ne peut pas passer sous 22 Ko, elle est conservée telle quelle et un message l'indique.
Windows peut afficher un avertissement au téléchargement des .bat : c'est normal. Tu peux les ouvrir avec un clic droit → « Modifier » pour vérifier leur contenu avant de les lancer.
