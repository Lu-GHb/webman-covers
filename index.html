Scripts pour Jaquettes WebMan PS3

À utiliser dans l'ordre : 1, 2, puis 3. Clique sur « Télécharger » pour récupérer un script.

1 - Jeux .ISO dans Dossier.bat Range chaque fichier .iso dans un dossier du même nom.
Télécharger
2 - Renommage Jaquettes.bat Renomme l'image de chaque dossier avec le nom du jeu .iso.
Télécharger
3 - Conversion Images PNG 120x120px.bat Convertit les images en PNG 120x120 de moins de 22 Ko (ImageMagick requis). Remplace les images d'origine.
Télécharger
Windows peut afficher un avertissement au téléchargement : c'est normal pour les fichiers .bat. Fais un clic droit → « Modifier » pour vérifier leur contenu avant de les lancer. Place le script dans le dossier qui contient tes jeux avant de l'exécuter.
